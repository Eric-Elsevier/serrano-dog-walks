# Serrano Dog Walks

Plain HTML and CSS, single page. No framework, no bundler, no build step.

```
index.html             The whole site
assets/daniel-walk.jpg       Hero photo
assets/serrano-trails-map.jpg Official Serrano nature trails map
robots.txt
_headers                Cloudflare Pages response headers
```

## Open it locally

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000.
